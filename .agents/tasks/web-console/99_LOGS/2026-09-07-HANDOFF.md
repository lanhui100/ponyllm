5. **验收不可用"靠 review 演示"**：必须配非零退出命令（学 WEB-01 教训）。

   `<AdminApiDoc as utoipa::OpenApi>::openapi()` 全限定（trait 不在作用域）。

   admin save 时 +1；若实现发现递增点无法落进 ConfigStore，需升级 consultant，
   不得静默跳过（security 明确要求）。
