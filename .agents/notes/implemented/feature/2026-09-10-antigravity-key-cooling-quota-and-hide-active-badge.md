# Agent Note: 移除密钥可用就绪徽标并在冷却状态下稳定展示用量指示

Status: implemented

## Problem

在 Web 端治理界面的密钥列表（`KeySubSection.vue`）中，当前各条目无论状态如何，都展示 `active`（"就绪" 绿色徽标）、`cooling_down`（"冷却中" 警示徽标）或 `disabled`（"已禁用" 徽标）。
用户提出如下痛点：
1. **可用状态视觉噪音**：密钥大多数时候处于正常的 `active` 可用状态，每个正常密钥前都悬挂一个“就绪”徽标显得视觉信息冗余、分散注意力。真正需要警示的是“冷却中”或“已禁用”这类异常/亚健康状态；
2. **冷却中用量与恢复指示不明确**：当 Antigravity 密钥由于上游 429 报错进入 `cooling_down` 状态时，如果尚未手动执行过连通性拨测探测配额，界面只显示占位的“点击右侧刷新查看用量”，无法清晰告知用户当前配额受限（0% 额度）以及该账号配额用尽后的恢复进度情况。

## Decision

1. **可用（`active`）状态不显示“就绪”徽标（`web/src/components/governance/KeySubSection.vue`）**：
   - 调整状态徽标条件渲染：当 `k.state === 'active'` 时不再渲染“就绪”徽标，仅在状态为非 `active`（如 `cooling_down` 冷却中、`disabled` 已禁用）时渲染相应的警示徽标；
   - 界面常规态更整洁宁静，异常状态更加聚焦醒目。
2. **冷却中（`cooling_down`）密钥自动呈现用量进度指示**：
   - 当密钥处于 `cooling_down` 状态时，即表明该 Key 在网关侧触发了上游配额耗尽或限流保护；
   - 在 Antigravity 服务商下，若该处于冷却中的密钥还没有探测记录（`!keyTestResults[k.id]`），自动将其视为配额已耗尽（0%）的状态并自动渲染用量进度条，明确展示红条 0% 并在 Tooltip 与文案中提示当前处于“冷却保护中 / 待恢复重置”；若已有探测数据则直接按探测的恢复时间和真实额度展示。
   - 确保用户一眼就能明确看到该冷却中账号的具体用量指示及恢复情况。

## Alternatives considered

- **方案 A：所有状态都不显示徽标**：会导致处于冷却中或被禁用的异常账号无法被及时感知，严重影响排障，否决。
- **方案 B：冷却状态下仅弹出文案提示“该密钥正在冷却”而不显示进度条**：无法直观看出 5h / 周窗口与恢复时间，体验不连贯，否决。
- **方案 C：仅隐藏“就绪”徽标保留异常徽标，且在冷却状态下稳定展示用量进度指示（采纳）**：视觉最清爽，状态最精准，信息传达最完备。

## Consequences

- 减少正常状态下的视觉干扰，突出异常状态；
- 用户能在冷却中直接看到清晰的 0% 警示红条与重置恢复指示，大幅提升配额排障与管理体验。
