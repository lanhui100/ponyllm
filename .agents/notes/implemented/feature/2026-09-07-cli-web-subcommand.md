# Agent Note: CLI新增web子命令启动控制台服务

Status: implemented

## Problem

此前启动 PonyLLM 服务仅支持 `ponyllm serve`，默认监听常用端口 `8080`，容易与本地其他开发服务发生端口冲突。此外，对于仅希望使用 Web 控制台的用户而言，`serve` 命名的直观性不足，且控制台输出以 API 网关路由为主，缺少醒目的浏览器访问入口与 Token 连接指引。

## Decision

在 `ponyllm` CLI 中新增专用的 `web` 子命令（支持 `ui`、`console` 别名）：
- **非公知高位默认端口**：默认监听 `127.0.0.1:18080`（非公知常用号段，避免 8080/8000/3000/5000 冲突），同时提供 `-p / --port <PORT>` 参数允许用户指定任意端口。
- **Web 友好型横幅**：启动成功后在终端醒目打印直达入口（`http://<addr>:<port>/app/`）以及当前访问凭据（Token），提供直观连接指导。
- **可选调起浏览器**：提供 `--open` 标志位，在桌面环境下可自动唤起系统默认浏览器直达控制台。
- **底层共享架构**：`Commands::Web` 内部复用网关核心装配与生命周期机制，强制启用 Web 静态托管（`no_web = false`），保持零代码冗余。

## Alternatives considered

- **仅将 `web` 作为 `serve` 的命令别名**：否定。纯别名无法覆盖非标准默认端口需求（`serve` 沿用配置文件或 8080），且无法定制针对 Web 控制台的高亮横幅与 `--open` 参数。
- **将默认端口设为 3000 或 8000**：否定。3000 和 8000 是常见前端/后端开发端口，冲突概率极高，18080 高位端口冲突概率极低。

## Consequences

- 用户可以直接通过 `ponyllm web` 或 `ponyllm web -p 18090` 一键启动 Web 控制台并获得醒目入口指引。
- 保证与现有 `ponyllm serve` 的向下兼容性，核心逻辑统一，无维护负担。
