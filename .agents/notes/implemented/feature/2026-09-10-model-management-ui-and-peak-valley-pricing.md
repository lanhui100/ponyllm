# Agent Note: 模型管理页面视觉交互优化与峰谷分时定价模型支持

Status: implemented

## Problem

当前 Web 控制台的模型管理与编辑交互存在若干视觉体验与业务能力局限：
1. **服务商卡片视觉不够简洁**：服务商卡片名称前的图标容器带有 `border border-orange-200/60` 边框，视觉层级稍重。
2. **模型编辑表单排版比例失调**：新建/编辑表单采用纯白色块或简单浅灰底，缺乏整体磨砂质感；且大部分字段名和输入框垂直堆叠撑满水平宽度，在大宽屏或卡片内比例失调。
3. **选中国际化配色不协调**：表单中的模态、协议、分级等选中状态大量使用紫色（purple）、青蓝色（indigo）高饱和度方案，与全局以黑白灰及中性色为主的极简风格冲突。
4. **价格模型单一**：原先仅支持静态的统一单价（输入、缓存、输出），无法满足上游服务商（如各种夜间折扣、分时降价政策）的峰谷分时定价需求，缺少按时段动态匹配价格估算与持久化支持。

## Decision

1. **服务商卡片图标去边框**：
   - 将 `ProviderCard.vue` 头部图标容器的 `border border-orange-200/60` 移除，保持纯净轻盈的圆角底色容器与自然阴影。
2. **模型编辑表单毛玻璃质感与2列栅格布局**：
   - 将内联编辑区域与新建表单背景改为精细的毛玻璃面板（`glass-panel` 或 `bg-white/60 backdrop-blur-md border border-white/60 rounded-xl`）。
   - 将表单字段按“字段名与输入组件同一行2列”进行布局（左侧标签，右侧输入控件/选项组），在宽屏下比例和谐匀称。
3. **黑白灰极简选中态**：
   - 彻底移除模态切换、协议覆盖、分级、标签等组件中的 `indigo` / `purple` / `emerald` 高饱和选中色；
   - 统一使用极简高对比黑白灰方案：选中态为 `bg-slate-900 text-white shadow-2xs font-semibold`，未选中态为轻微中性灰悬浮，保持严谨克制的现代界面风格。
4. **后端定价模型与运行期峰谷分时动态计费**：
   - 在 `PricingConfig` 中引入统一价格与峰谷模式（`PricingMode::Uniform` 与 `PricingMode::PeakValley`），并新增时段列表 `pricing_periods: Vec<PricingPeriod>`，每段包含起始时间 `start_time`（如 "08:00"）、结束时间 `end_time`（如 "24:00"）以及对应的三项单价。
   - `estimate_cost` 扩展支持传入当前时间戳或本地时段，动态查找匹配时段定价；当无匹配或未启用峰谷模式时平滑回退到统一价格。
   - 同步适配 `ModelConfig`、`CreateModelPayload`、`UpdateModelPayload`、`ModelView` 及 OpenAPI 契约与序列化。
5. **前端峰谷价格交互**：
   - 将“模型专属价格”文案精简为“价格”，默认选择统一价格（单组输入、缓存、输出单价），可无缝切换到“峰谷模式”，支持动态添加/删除多个时段与单价配置。

## Alternatives considered

- **仅在前端做峰谷模式展示，后端只存一个平均价**：虽然实现简单，但无法真实反映实际请求运行发生时（如夜间低谷）的精确计费与成本分析，且破坏了配置治理的一致性。因此决定全栈贯通，后端原生支持时段定义并在估算成本时根据当前时段精准命中。
- **固定双时段（高峰与低谷）而不是自由时段列表**：虽然两段制更简单，但各家上游服务商（如智谱、深度求索、百度、阿里等）的时段划分不尽相同（例如有的以 00:30-08:30 优惠，有的多档优惠）。采用自定义多时段列表能更优雅、更通用地适配各类分时优惠。

## Consequences

- 服务商卡片与模型编辑表单视觉更加清爽纯粹，消除了突兀的边框与不协调的亮色，整体毛玻璃与黑白灰质感浑然一体。
- 字段名与输入组件采用双列对齐后，横向视觉比例更加紧凑合理。
- 完整支持峰谷分时定价，满足上游分时段降价优惠场景，并保持与旧配置完全向下兼容。
