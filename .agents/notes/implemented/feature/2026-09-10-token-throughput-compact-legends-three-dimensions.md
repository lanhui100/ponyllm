# Agent Note: Token Throughput Multi-Dimension Switch with Compact Legends

Status: implemented

## Problem

此前在恢复「提供商 / 模型」维度切换后，带来了新的体验与架构问题：
1. **标签文案冗余**：“按 Provider / 按模型”带有“按”字，占用横向空间且文案不够极简；
2. **算力构成视角丢失**：直接把原本的大盘输入/输出/缓存命中三段堆叠替换掉，导致运维监控缺失了从 Token 构成（输入、输出与上下文缓存命中率）审视算力分布的全局能力；
3. **多模型图例排版爆炸**：随着后续接入模型数量增多（可能有 5~20 个以上），ECharts 原生图例多行换行会侵占纵向空间并遮挡柱状图主体，难以兼顾空间整洁度与图例信息完整性。

## Decision

1. **统一三维 Switch 切换**：
   - 将卡片右上角的 Switch 拓展为三档：`类型`（输入/输出/缓存命中）、`提供商`（Provider）、`模型`（Model），彻底去除了“按”字；
   - 默认选中 `类型`，保留输入/输出/缓存命中全量三段堆叠柱状图、提示 Tooltip 与缓存命中节省百分比计算。
2. **多模型/提供商紧凑图例方案**：
   - 采用用户采纳的 **Top 2 色块常驻 + 其余“+N ...” Hover 展开完整图例** 方案；
   - 在图表上方右侧紧凑渲染排名前 2 的用量模型/提供商（带对应颜色圆角方块与截断名称）；
   - 当系列多于 2 个时，渲染 `+N ...` 浅色徽标；用户鼠标悬浮（Hover）时通过 `<UiTooltip>` 气泡浮层展示完整系列的色块、名称与总消耗 Token（格式化整数与 tabular-nums 对齐）；
   - 柱状图数据层将 Top 5 重点序列作为独立堆叠色块渲染，其余小碎流收敛为“其他”色块（#94a3b8），既保证图表信息丰富，又避免色彩过载。
3. **Tooltip 插槽升级**：
   - 升级 `UiTooltip.vue`，支持可选 `content` prop 与 `<template #content>` 自定义插槽共存，使得任意组件可安全渲染结构化悬浮图例或说明信息。

## Alternatives considered

- **纯图表内置滚轮图例（type: 'scroll'）**：移动端和触摸板手感不佳，图例小箭头样式风格与系统极简设计语言不搭。
- **限制只展示 Top 2 数据**：会造成长尾模型用量在视觉上丢失。折中采用 Top 5 堆叠 + 独立“其他” + 图例区 Top 2 紧凑展示 + Hover 完整浮层是专业监控系统的最佳实践。

## Consequences

- 完美整合了「Token 算力类型堆叠」与「提供商 / 模型流速分布」两代核心能力，用户自由一键切换；
- 解决了多模型接入时图例空间爆炸问题，界面保持瑞士极简风格且信息下钻毫不打折；
- 单元测试与端到端构建全部通过。
