# Agent Note: Web 控制台现代极简 UI/UX 重构

Status: implemented

## Problem

原 Web 控制台（web-console）存在若干用户体验和视觉架构痛点：
1. 治理视图（GovernanceView）将 Provider、Model、Key 割裂在三个独立 Tab 中，用户心智被打碎，无法直观感知服务商到模型和密钥的从属层级。
2. 界面风格传统，过度依赖 1px 边框分割区域，缺乏开阔通透的极简现代呼吸感。
3. 表单操作依赖侧拉抽屉（Drawer），操作链路冗长且打断上下文；操作按钮以长文字为主，视觉噪音大，缺少纯语义图标与 Hover Tooltip。
4. 模型思考强度（Thinking Effort）参数平铺且混杂，缺乏分层折叠与面向普通用户的易懂解释。
5. 仪表盘图例与指标卡视觉较厚重，缺乏极简的现代信息呈现。

## Decision

1. **集成 Tailwind CSS 4+ 与 shadcn-vue 规范**：
   - 接入 `@tailwindcss/vite` 与 `tailwindcss@4.3.3`。
   - 引入 shadcn-vue 的设计 Token（CSS 变量规范），构建纯原生、零外部黑盒依赖的轻量组件（Button, Badge, Card, Tooltip, Collapsible）。
2. **重构为以服务商为中心的三合一平滑内联架构**：
   - 一级服务商卡片（Provider Card）：无边框卡片、软阴影与厂商标识，常用操作（⚡测速、＋模型、＋密钥、✎编辑、🗑删除）一等显示。
   - 二级模型区：模型名称、Tier 分级与上下文一等常显；高级参数（含思考强度 4 档映射 `thinking_default`/`thinking_max`、协议、代理）优雅折叠。
   - 二级密钥区：脱敏掩码、延迟徽章与快速测试/删除。
   - **平滑内联展开**：彻底淘汰侧拉抽屉，点击“+ 服务商”、“+ 模型”、“+ 密钥”或“编辑”时均在当前位置平滑展开内嵌表单。
3. **文案精简与极简语义图标系统**：
   - 导航精简为“模型管理”；按钮精简为图标 + “模型” / “密钥” / “服务商”。
   - 采用纯图标按钮 + accessible title/aria-label；通俗化解释通过 `ⓘ` Hover Tooltip 呈现。
4. **Dashboard 极简图例改造**：
   - 状态胶囊呼吸灯化；KPI 指标卡软阴影去厚边框；ECharts 图表升级为极简淡渐变面积图。
5. **系统性端到端验证套件**：
   - 落地 `modern-ui.flow.test.ts`，全量覆盖平滑内联交互、思考强度映射、纯图标 Tooltip、状态胶囊、安全只读与 412 冲突拦截。

## Alternatives considered

- 引入重量级组件库（如 Naive UI 或 Element Plus）：虽然开箱即用，但在当前离线内网环境下存在外部依赖缺失风险，且打包体积大、定制化程度低，无法达到极简精致的定制设计要求，故否决。
- 维持 Tab 架构仅微调样式：无法解决用户在多 Tab 间来回跳转的心智割裂问题，从根本上违背“以服务商为中心”的直观拓扑，故否决。
- 继续保留侧边抽屉（Drawer）：侧拉抽屉割裂了用户在主卡片上的操作视野，尤其在深层嵌套时体验差，不符合现代平滑内联展开的轻量化趋势，故否决。

## Consequences

- 彻底消除了侧拉抽屉带来的割裂感，所有配置均可原位即时查看和就地修改。
- 界面视觉全面迈向极简轻主题，去除 1px 冗余边框，采用高辨识度的微阴影与语义图标。
- 思考强度参数获得清晰的 4 档映射选择器与用户友好释义。
- 保证了对既有端到端测试与安全契约（`governance.flow.test.ts`、`views.flow.test.ts`）的 100% 向后兼容。
