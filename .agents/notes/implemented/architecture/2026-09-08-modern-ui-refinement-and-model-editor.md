# Agent Note: Web 控制台现代极简视觉深化与模型编辑全按钮化重塑

Status: implemented

## Problem

在第一阶段现代极简改造后，Web 控制台已实现去抽屉化与基础折叠，但仍面临三处体验瓶颈：
1. **排版字号偏小与阅读疲劳**：大量使用 10px-12px 微小字体，缺少现代等宽数字（tabular figures）支持与开阔行高，高分辨率屏幕阅读费力。
2. **色彩缺乏个性且偏传统工业蓝**：沿用传统科技蓝与刺眼原谅绿，色彩语义过于常规，未形成高级轻量质感。
3. **模型编辑交互不够傻瓜化**：分级与上下文仍依赖下拉或输入框，思考强度同时暴露“默认”与“最大上限”增加用户困惑，缺乏直观的多模态（文字/图片/视频/音频）纯图标开关，价格与小众参数未能在“高级”层级合理收拢。

## Decision

1. **现代无衬线字体栈与字阶放大**：
   - 接入系统现代无衬线字体栈，开启 `tabular-nums` 等宽数字特性。
   - 基础正文/表单提升至 14px，辅助标签与微标提升至 12-13px，看板核心指标放大至 32-36px 粗体，行高提升至 1.5-1.6。
2. **个性时尚轻色彩体系（风格 2 色块流 + 鸢尾紫点缀）**：
   - 构建无边框阶梯体系（Surface L0~L3），用柔和云灰（`#F8F9FA`）与下沉色块（`#F1F3F5`）自然区分卡片与嵌套编辑区，移除生硬描边。
   - 采用电光鸢尾紫（Iris Violet）作为克制主题色，状态色采用低饱和冷翠玉（Jade）、暖琥珀（Amber）与烟熏胭红（Rose）。
3. **模型编辑直觉式全按钮选项化与层级下沉**：
   - 分级（Tier）：3 档（Flagship / Standard / Light）平铺按钮分段选项器。
   - 上下文窗口：快捷容量按钮组（8K / 32K / 128K / 1M / 自定义）。
   - 思考强度：彻底淘汰“最大上限”，精简为单一档位（Off / Low / Medium / High）按钮选项器。
   - 多模态能力：纯图标按钮组（文字、图片、视频、音频），悬停 Tooltip 说明，点击切换激活高亮。
   - 折叠降级：计费单价（输入/缓存/输出）与协议下沉为模型二级折叠层，标题直达“高级”，默认收起。

## Alternatives considered

1. **方案 A：保留最大思考强度上限与传统输入框**：
   - 优点：完全映射底层 protocol 的全部配置项。
   - 缺点：大部分终端用户难以理解“默认强度”与“最大上限”的钳位机制，操作链路长、认知负担过重，违背“面向用户、傻瓜化操作”的原则。
2. **方案 B：使用深色暗黑主题（Dark Mode）**：
   - 优点：视觉冲击力强，符合极客偏好。
   - 缺点：用户明确提出轻主题颜色（Light theme）；且白天及高照度环境下高对比暗黑易产生眩光；因此采用温和云灰配色的轻主题无边框方案。
3. **方案 C：弹窗 Modal 承载模型编辑**：
   - 优点：编辑区域大，不受列表空间限制。
   - 缺点：打破就地沉浸感，与上一轮确立的“去抽屉、就地平滑展开”原则违背；通过下沉色块（Surface L2）和“高级”折叠收拢，完全可以在行内平滑舒适展示。

## Consequences

1. **正向收益**：
   - 界面视觉品质显著提升，消除刺眼传统蓝绿与 10px-12px 微小文字疲劳，大盘指标粗体等宽极易辨识。
   - 模型编辑操作完全傻瓜化，分级、上下文预设、思考强度均可一键直选；多模态支持状态一目了然。
   - 价格与底层协议下沉至“高级”折叠区，主界面信噪比大幅提升。
2. **测试维护**：
   - 端到端测试已覆盖按钮分段选择器与模态纯图标切换，保障后续迭代不倒退。
