# Agent Note: Web 全局多色彩撞色渐变与毛玻璃背景方案

Status: implemented

## Problem

PonyLLM Web 控制台目前采用的是偏平面实色的白/灰底色（`#f8fafc` 底色，卡片采用纯白 `#ffffff`）。
1. **背景单调平淡**：纯浅灰底色缺乏层次与空间景深感，视觉品质偏静态单调，无法体现高性能现代 AI 平台与新潮 Web 应用的灵动质感。
2. **缺乏现代毛玻璃（Glassmorphism）衬底支撑**：导航栏（`NavBar`）、模态框（`Modal`）、悬浮提示与主要卡片容器无法展现半透明与模糊折射的通透层次；如果直接在纯白/纯灰底色上使用 `backdrop-filter: blur(...)`，上层组件因底色缺乏色彩变化而无法产生任何毛玻璃折射与光影通透感。
3. **色彩与对比度需要平衡**：需要在营造极富冲击力的多色彩撞色渐变（如暖日橙、电光紫、板岩青、琥珀金的多光斑流体融合）的同时，严格保障文字与数据指标的阅读清晰度与 WCAG AA 对比度，且不可因复杂动效造成 GPU 压力或滚动重绘性能下降。

## Decision

在 Web 控制台落地全局多色彩撞色微动态渐变方案与毛玻璃（Glassmorphism）设计体系：
1. **全局撞色渐变底衬（Multicolor Contrasting Ambient Gradient Layer）**：
   - 在顶层布局（`App.vue` / `style.css`）构建全局固定定位且穿透事件的背景层（`global-ambient-bg`）；
   - 彻底废除紫色，选用高对比、强饱和的暖日橙/珊瑚橙（Warm Solar/Coral Orange `#f97316`）与深岩青/湖水绿（Slate Cyan/Teal `#0d9488` / `#0f766e`）双主核体系，辅以金橙与深青上下交织；
   - 严格收敛光斑中心距离：在大屏（2K/4K）与常规屏幕下，将橙与青的几何中心间距紧凑锁定在 20%~25% 视口范围内，杜绝各居一隅孤立稀释，形成高浓度的撞色交界与流体漫反射；
   - 采用 75px 高斯模糊与 0.5~0.6 浓郁起始透明度，让浅冷底色（`#f1f5f9`）与鲜亮撞色剧烈冲撞，为上层折射提供饱满光源。
2. **毛玻璃分层规范（Glassmorphism Design Tokens）**：
   - 升级 `.swiss-card`、`.glass-panel` 与通用容器：大幅减弱白底阻隔，不透明度降至 `rgba(255, 255, 255, 0.40~0.45)`；
   - 将 blur 滤镜降低至 sm / xs 级别（`blur(4px)`），配合 `saturate(140%)` 与极细微透明边框（`rgba(255, 255, 255, 0.40)`），消除厚重乳白糊化感，形成高度清澈穿透的现代毛玻璃；
   - 顶部导航栏 `NavBar` 彻底去除白底，采用 `bg-slate-900/5 backdrop-blur-md border-b border-slate-900/5`，实现极简纯净的穿透交互；
   - **全面重构模型管理（GovernanceView）与子组件内部容器并消除套娃多重层级**：
     - 将 `ProviderCard` 内部折叠区、模型协议配置框微透化，彻底去除外层多余边框与白色背景；
     - 彻底去除第三层级密钥与模型子卡片、子条目的多余背景与边框（`bg-transparent border-none`），消除嵌套套娃线框感，仅保留轻微交互悬浮高光（`hover:bg-white/35`）；
     - `StrategySection` 策略卡片升级为 `bg-white/40 border-white/50 backdrop-blur-xs`，保证深层嵌套结构轻盈通透。
3. **无障碍与稳健性保障**：
   - 保持全部核心文本与交互元素的高对比度（深冷石墨灰 `#0f172a` / `#1e293b`），文字排版及关键按钮不降低对比度；
   - 添加 `@media (prefers-reduced-transparency: reduce)` 支持，当用户开启系统减弱透明度时自动回退为纯白不透明底色。

## Alternatives considered

- **CSS Canvas / WebGL 实时着色器（Shader）**：虽然可以实现流体粒子与无级动态光晕，但在长时间挂机运维监控场景下会持续占用显卡与电量，且容易与 ECharts 渲染冲突，纯 CSS 叠加径向渐变与高斯模糊更轻量稳定。
- **单色单方向线性渐变（如单一橙到蓝渐变）**：单一双色渐变在大幅面滚动时显得单调，且中间过度容易产生浑浊的灰度带；多色彩多中心径向撞色光斑（Radial Orbs）能产生更加自然丰富的色彩交汇与明暗景深。

## Consequences

1. **视觉跃升**：全站获得现代、通透、高颜值的多色彩撞色渐变光感，上层卡片与导航栏的毛玻璃折射效果立体生动。
2. **兼容性完备**：所有已有的 15 个测试套件、72 项单测和端到端测试均完全兼容，零功能断言破损。
