# Agent Note: Web 控制台暖橙深青视觉重塑与连通性大盘升级

Status: implemented

## Problem

现有 PonyLLM Web 控制台在大盘（Dashboard）体验与视觉设计上存在以下不足：
1. **视觉排版与配色局限**：界面字体偏小（基础 14px，大量 12px），阅读密度过大易视觉疲劳；主题色为冷调鸢尾紫，缺少温暖现代的品牌辨识度与冷暖平衡的质感。
2. **状态反馈形式简陋**：网关状态仅有单点闪烁灯，Provider 仅有静态 Badge，无法直观反映最近一分钟的连续可用性波动与网络延迟变化。
3. **指标视图缺乏多周期与多维细分**：大盘目前仅展示短时实时折线，缺少 24小时 / 7天 / 30天 周期切换；图表形式单一，无法体现 Token 吞吐的离散分布；缺乏针对各 Provider 与 Model 维度的 Token 分布查看能力。

## Decision

全面升级 Web 控制台的视觉系统与 Dashboard 交互体验：

1. **字体放大与暖橙深青配色方案**：
   - 基础字号提升（`body` 提升至 15px/1.6，标题、数值、表格与卡片内边距等比放大），优化行高与字间距；
   - 确立 **暖橙色（主色，Warm Amber/Orange）+ 板岩青/深青黛色（辅色，Deep Slate Cyan）** 的 Tailwind 4 颜色搭配，以冷暖对立实现专业监控工具的清晰与现代轻量质感；全站组件（NavBar、UiButton、UiBadge 等）收敛统一；
   - 统一三色连通性定义：及时（绿色，< 300ms）、一般（黄色，300ms ~ 1000ms）、超时（红色，≥ 1000ms 或服务断开）。

2. **连通性状态条组件（`UptimeBars.vue`）通用封装**：
   - 渲染连续排列的 40 根微柱状条（覆盖最近 1 分钟，每根 1.5 秒采样时隙）；
   - 右侧展示最新响应耗时，具备健全的 `null`/`undefined` 数字类型守卫，异常时安全展示 `--`；
   - Hover 提供详细悬浮气泡提示（时分秒、具体耗时、状态判定）；
   - 网关状态栏与各 Provider 状态列全面接入该组件，作为系统统一的连通性图例。

3. **提供商状态区域重塑**：
   - 表格标题升级为“提供商状态”，补充防挤压防折行排版；
   - 头部增加 **24小时 / 7天 / 30天** 周期切换 switch（默认选中 24 小时）；
   - 新增 **Token 总量** 字段展示（各 Provider 累计 Token 消耗与占比）；
   - 状态列全面采用 `UptimeBars` 呈现各 Provider 连通性切片。

4. **四大核心指标与图例深度优化**：
   - 默认周期统一采用 **24小时**，支持 24h / 7d / 30d 切换；
   - 实时轮询（1.5s）与时序历史拉取（初次挂载、切周期、低频60s）彻底解耦，消除请求风暴；
   - **QPS**：采用平滑折线面积图（Smooth Line with Area Gradient），展现并发洪峰；
   - **Token 吞吐量**：采用柱状分布图（Bar Chart），配置 **Provider 维度 / Model 维度** 切换 switch，设置 `notMerge: true` 防幽灵系列残留；
   - **延迟与速率**：采用波形图（Waveform / Spline Area），呈现 TTFT 与 TPS 的起伏波动；
   - **故障率**：采用微波阶梯折线图（Step Line），突出错误脉冲；
   - ECharts 实例全量接入 resize 防抖与组件销毁时的完整内存释放。

## Alternatives considered

1. **方案 A：全量指标均采用折线图展示**：
   - 优点：组件通用、实现成本低。
   - 缺点：Token 吞吐属于典型周期累积量，折线图无法有效表达各 Provider/Model 在各时间桶的对比与堆叠分布；柱状图更符合业界吞吐量统计的最佳实践。
2. **方案 B：纯暖色系双色方案（暖橙 + 棕红/卡其）**：
   - 优点：色调统一温暖。
   - 缺点：长时间注视易产生视觉倦怠，且在图表中缺乏冷色通道对关键正常状态与关键基线的冷暖对比；板岩青辅色能有效平衡暖橙的高饱和度，提升界面耐看度与专业度。
3. **方案 C：连通性状态采用圆形小点（Dots）阵列**：
   - 优点：代码简单。
   - 缺点：圆点横向占用空间大，40 根圆点在不同分辨率屏幕下容易溢出或难以对齐；微型竖条（Bars）垂直拉伸感强、更紧凑且更易于对齐阅读。

## Consequences

- Web 控制台在阅读舒适度与现代设计质感上显著提升；
- UptimeBars 作为通行标准图例，在网关与各供应商处得到一致性复用；
- ECharts 实例生命周期受控无泄漏，高频切换无幽灵数据残留。
