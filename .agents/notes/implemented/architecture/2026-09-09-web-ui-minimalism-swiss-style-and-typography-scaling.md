# Agent Note: Web 控制台瑞士极简风格 (Minimalism & Swiss Style) 与字号放大重构

Status: implemented

## Problem

PonyLLM Web 控制台（web-console）此前在视觉与人机交互体验上存在以下痛点：
1. **字体普遍过小且阅读吃力**：全局基准字号硬编码为 15px，且在表单控件（Label/Input/Select）、操作按钮（UiButton）、提示文案与状态徽标中大量滥用 `text-xs`（12px）甚至 `text-[11px]`。在 2K/4K 高分屏下极其微缩紧绷，长时间阅读与运维盯盘极易产生视觉疲劳。
2. **视觉语言与高吞吐底层网关气质脱节**：原界面采用暖橙主色配合浅灰大面积漫反射阴影（`borderless-card`），呈现偏向日常轻量 SaaS，缺少 Rust 高性能网关、云原生基础设施与工程平台特有的严谨、精密与硬朗骨架感。
3. **层级分割依赖阴影，结构界限较弱**：在服务商（Provider）到模型（Model）与密钥（Key）的三合一治理展开时，依赖下沉背景色块与软阴影，缺乏工整的工程引导线与微边框约束。

## Decision

全面采纳 `ui-ux-pro-max` 推荐的 **Minimalism & Swiss Style（现代工程极简主义 / 瑞士国际风格）** 并完成字号阶梯整体跃升重构：
1. **排版系统与字号阶梯整体跃升（Typography Hierarchy Overhaul）**：
   - 全局基准字号提升至 16px（`1rem`），正文行高设定为 1.6；
   - 杜绝小于 12px 的超小字体。表单 `<label>`、`<input>`、`<select>` 及默认 `UiButton` 全部由 12px 提升至 14px（`text-sm`），提供充裕的点击与输入空间；
   - 状态徽章（`UiBadge`）与微型元数据设定为 12~13px，辅以加粗中等字重，确保小尺寸下的锐利辨识；
   - 数字与指标卡主数值升级为 26~28px，保持 `font-mono tabular-nums font-bold` 等宽对齐。
2. **1px 精密微边框与网格骨架取代大面积阴影**：
   - 弃用大范围软阴影，建立清晰严密的 Slate 1px 细线系统（`border border-slate-200/90` 与 `.swiss-card`）；
   - 背景采用纯白（`#FFFFFF`）与冷碳灰（`#F8FAFC`）微差分层，圆角收敛为克制干练的 `rounded-xl` / `rounded-lg` / `rounded-md`；
   - 引入 1.5px 树状层级引导线（Rail Guide），使三层内联嵌套展开具备直观的目录树拓扑感。
3. **沉稳工程中性色与高对比功能语义色**：
   - 以 Slate/Zinc 冷炭黑灰为主基底，主操作采用高对比深石墨黑，状态反馈保留翡翠绿（Emerald）、琥珀橙（Amber）与故障绯红（Rose）纯语义色。

## Alternatives considered

- **Dark Mode (OLED) 赛博遥测控制台**：虽然与终端 TUI 极度共鸣且非常适合夜间盯盘，但对当前基于浅色构建的完整表单组件改造成本较高，且部分用户在常规办公日光环境下偏好高清晰高反差的明亮极简工程界面。故作为后续主题扩展项保留，本次优先推进适用面更广的工程极简主义。
- **Bento Box Grid 模块化便当盒风格**：虽然圆角与毛玻璃视觉前沿，但在模型与密钥高密度深层嵌套治理时，非对称卡片容易浪费纵向阅读流空间，不如瑞士网格的规整高效。
- **仅修改局部 CSS 字体大小而不重构视觉骨架**：治标不治本，若不重构边框、内边距与行高体系，单纯强行放大字号会导致卡片拥挤破损，必须配套进行 1px 精密微边框与组件高度调整。

## Consequences

1. **字号彻底舒展**：全系统彻底消除了难以看清的 10px/11px 微缩紧压字体，所有正文、表单输入框、下拉框、操作按钮均提升至 13px/14px（大尺寸按钮 16px），长时间查阅与操作舒适度大幅提升。
2. **工程美学确立**：建立了现代瑞士国际主义的设计 Token（`.swiss-card`、`.surface-inset`、`.tree-rail`、`.segment-track`），彻底废除遗留的漫反射阴影，形成高度统一、硬朗利落的高性能网关控制台质感。
3. **完成对抗审核闭环与物理健壮性加固**：
   - 调度 3 位对抗性 Auditor 全面体检，修复只读模式防御性断言、48px 虚拟滚动 CLS 抖动消除、滚动条错位自适应；
   - 彻底修复 `FrameDrawer` 超长端点 Grid 坍塌与穿透滚动；全量纯图标补充 `aria-label` 与 `role="tooltip"`，WCAG 2.1 AA 对比度与可访问性全面达标。
4. **全量契约兼容**：全量 13 个测试套件、61 项自动化端到端测试 100% 保持绿灯，类型检查与代码规范检查 0 错误 0 警告通过。
