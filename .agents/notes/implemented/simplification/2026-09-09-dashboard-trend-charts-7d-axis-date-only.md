# Agent Note: Dashboard Trend Charts 7d Axis Date-Only Formatting

Status: implemented

## Problem

在 Web 控制台的 Dashboard 页面中，“趋势与指标分布”图表支持 24小时、7天与30天三种周期回溯。
在 7 天维度下，横轴时间戳此前格式化为 `MM/DD HH:00`（如 `09/02 14:00`），包含了具体小时时间，导致横坐标文本过长且信息冗余（30天维度仅显示 `MM/DD`，而7天维度带时间破坏了一致性，并且挤占了横轴有限的横向排版空间）。

根据产品设计需求，7天维度的横轴不应该带有时间，仅展示日期（`MM/DD`）即可。

## Decision

修改 `web/src/components/TrendCharts.vue` 中 `formatTimestamp` 函数对 `7d` 维度的格式化逻辑：
- 将 `7d` 维度的横轴时间格式从 `MM/DD HH:00` 简化为 `MM/DD`，与 `30d` 维度保持一致；
- 仅当为默认的 24小时（`24h`）实时维度时，保留 `HH:mm` 级别的时间展示；
- `30d` 与 `7d` 均统一采用纯日期格式 `MM/DD`。

## Alternatives considered

- **保留小时但缩小字号或竖排旋转展示**：虽然可以容纳时间，但 7 天宏观趋势分析主要聚焦于日间趋势对比，过长的小时文本会产生严重的视觉噪点，且与极简主义设计规范相冲突，故否决。
- **动态依据分辨率隐藏时间**：增加了图表配置的复杂度，且 7 天维度下统一仅展示日期 `MM/DD` 语义最明确、最整洁，故否决。

## Consequences

- 7天维度的四个趋势图（QPS、Token 吞吐量分布、延迟与速率、故障率）横轴标签清爽干净，仅展示日期 `MM/DD`；
- 避免了横坐标文本拥挤重叠，提升了看板的可读性与视觉美感；
- 现有单元测试及端到端测试均通过。
