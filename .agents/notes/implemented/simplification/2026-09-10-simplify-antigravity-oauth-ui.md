# Agent Note: 简化 Web 控制台 Antigravity 授权面板与视觉交互层级

Status: implemented

## Problem

在 PonyLLM Web 控制台的 Google Antigravity 授权面板中，存在多处冗余的工程化说明与复杂的视觉修饰：
1. **代理状态感知过于繁杂**：带有背景框、边框、冗长说明文案和复杂复制命令按钮，视觉权重过高，喧宾夺主；
2. **冗余的特性说明卡片**：展示了“内置特性与自动挂载”提示卡片，对日常使用用户而言属于无须解释的技术实现细节；
3. **授权链接展示区域过小且缺乏防篡改明确性**：单行文本截断展示无法看全完整 URL，且“前往 Google 授权”按钮为普通的 outline 描边样式，未能突出为主行动点；步骤一带有“（支持 SSH 隧道与本地自动闭环）”工程化赘述；
4. **回填提示语繁琐且提交按钮语义冗长**：步骤二标题含有“(弹窗自动闭环，亦可在此手动粘贴兜底)”，提示文案过长且未讲清楚如何复制回填链接与授权码；提交按钮为“确认授权并创建”，文案较长。

## Decision

1. **极大简化代理状态检测**：
   - 彻底去除外层大背景块与边框，去除额外注释与复制命令按钮；
   - 仅平铺呈现本地代理状态（小圆点指示灯 + 运行状态文本）与轻量「重新探测」按钮。
2. **移除内置特性与自动挂载卡片**：
   - 彻底删除“内置特性与自动挂载”提示区域，保持面板清爽。
3. **重塑「前往 Google 授权」交互层级**：
   - 移除标题中“（支持 SSH 隧道与本地自动闭环）”文字；
   - 将「前往 Google 授权」按钮设为高对比度主色突出显示（醒目高亮），提示为核心主操作；
   - 授权链接改为多行文本区域（`rows="3"`），支持展示完整长链接，并设置 `readonly` 禁止用户编辑。
4. **精简重定向 URL 与 Code 回填提示**：
   - 移除步骤二中冗长后缀“ (弹窗自动闭环，亦可在此手动粘贴兜底)”；
   - 提示文案精简为清晰明了的逻辑：说明会自动授权；如自动授权未完成，则复制浏览器地址栏的完整重定向链接（`http://.../oauth2callback?code=...`）或授权码（`code=` 后的内容）至输入框；
   - 提交按钮文案由“确认授权并创建”精炼为“确认授权”（提交时状态相应精简为“正在授权...”）。

## Alternatives considered

- **方案 A：保留代理状态的大卡片但隐藏注释**：依然会占据大面积视觉焦点，破坏整体扁平与现代感，否决；
- **方案 B：将授权链接完全隐藏只留按钮**：当浏览器弹窗被阻止或在无 GUI 环境使用时，用户无法直接复制链接在其他设备打开，影响可用性，保留多行只读 textarea 是最佳折衷；
- **方案 C：全流程精简交互规范（采纳）**：视觉重心全面向核心主路径（前往授权 -> 自动/备用回填 -> 确认授权）靠拢。

## Consequences

- Antigravity 授权面板变得极度清爽利落，去除无关噪音；
- 用户一眼即可识别主操作按钮与当前代理连通性；
- 授权链接可完整阅读且安全只读，回填说明通俗易懂；
- 保持现有的自动 postMessage 换票与焦点恢复剪贴板自动感知功能完好无损。
