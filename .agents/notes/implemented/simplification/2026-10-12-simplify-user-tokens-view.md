# Agent Note: 精简用户 Token 页面交互与文案

Status: implemented

## Problem

在 ponyllm web 的“我的 Token”视图（`web/src/views/TokensView.vue`）中存在两处冗余设计：
1. Token 列表中展示了“启用/停用”状态徽标和“停用/启用”按钮。对自助 API Token 用户而言，核心诉求是创建、复制、轮换和删除，频繁切换启停并非主频动作，状态徽标和按钮增加了视觉噪音；
2. 新增 Token 弹窗与创建/轮换后的复制结果弹窗中充斥了冗长啰嗦、重复嵌套的提示语与括号解释（如输入框 label 上的重复注释、结果弹窗中大段重复的“安全提醒”大框与“我已安全复制，关闭”长文本），信息信噪比偏低。

## Decision

1. **去除状态徽标与切换按钮**：
   - 从 Token 列表中移除 `UiBadge` 启停状态徽标；
   - 移除 `UiButton` 启停切换按钮，仅保留“轮换”与“删除”高频操作。
2. **精简新增 Token 弹窗**：
   - 名称输入框 label 简化为 `名称 *`，placeholder 统一为 `Token 名称`；
   - 用量上限 label 简化为 `用量上限`，placeholder 简化为 `留空为不限`；
   - 模型白名单 label 简化为 `允许模型`，placeholder 简化为 `留空为全部，多个用逗号分隔`。
3. **精简复制 Token 弹窗**：
   - 彻底移除重复啰嗦的绿色大段“安全提醒”卡片；
   - 保留顶部弹窗标题与简明 `明文仅展示一次` 徽标；
   - 凭证 label 简化为 `访问凭据`，底部按钮精简为 `关闭`。
4. **测试断言对齐**：
   - 在 `web/src/views/TokensView.test.ts` 中补充不含停用/启用徽标与按钮的断言，更新弹窗断言，确保全量测试通过。

## Alternatives considered

- 保留启停按钮但隐藏在下拉菜单中：否定。自助 Token 场景下轮换和删除完全覆盖凭证生命周期管理，不需要额外的状态流转负担。
- 在复制弹窗保留多行警示：否定。顶部徽标已明确“明文仅展示一次”，重复的大段套话只会阻碍用户快速复制凭证。

## Consequences

- 界面清爽极简，视觉聚焦在核心的凭证名称、用量、轮换与删除操作上；
- 新增与复制弹窗交互路径缩短，零多余噪音；
- 前端全套单元测试与构建 Exit Code 0。
